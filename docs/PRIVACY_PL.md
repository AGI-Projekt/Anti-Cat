# Prywatność CAT

- Ustawienia są przechowywane lokalnie w magazynie rozszerzenia.
- CAT nie wymaga konta ani telemetrii do podstawowego działania.
- Pełne URL nie powinny trafiać do dziennika domyślnie.
- Zewnętrzne listy filtrów są pobierane tylko po dodaniu źródła przez użytkownika i przyznaniu niezbędnego dostępu.
- Nie umieszczaj kluczy licencyjnych w kodzie rozszerzenia.
- Importowane konfiguracje i listy należy walidować przed aktywacją.
- Użytkownik powinien mieć możliwość wyłączenia ochrony oraz Cleaner.

Ta dokumentacja opisuje założenia projektu. Przed wydaniem produkcyjnym należy sprawdzić je względem faktycznego kodu, manifestów i zachowania przeglądarki.
